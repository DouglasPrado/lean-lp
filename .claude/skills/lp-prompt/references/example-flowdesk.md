# Exemplo: FlowDesk PROMPT.MD

```markdown
Leia o CLAUDE.md e siga o workflow completo para criar uma landing page do zero.

O produto é o **FlowDesk** — um SaaS de gestão de projetos com IA para equipes remotas.

Informações do produto:

- Nome: FlowDesk
- Tagline: "Gestão inteligente para times que trabalham de qualquer lugar"
- Público: CTOs, tech leads e gerentes de produto em startups e scale-ups
- Diferencial: IA que sugere priorização automática de tasks, detecção de blockers e previsão de atrasos
- Preço Starter: R$59/mês, Pro: R$179/mês, Enterprise: sob consulta
- Cor primária: #6C3CE1 (roxo)
- Cor secundária: #10B981 (verde esmeralda)

Comece pela Fase 0 e siga todas as fases até a Fase 4 (SEO).
Em cada fase, leia a skill correspondente antes de agir.
No copy, preencha o conteúdo real para o FlowDesk (não deixe placeholders).
```

## Por que este exemplo funciona

- **Nome**: curto, memorável, combina "Flow" (processo) + "Desk" (trabalho)
- **Tagline**: 9 palavras, foca no benefício (gestão inteligente) + público (times remotos)
- **Público**: específico (cargo + tipo de empresa), não genérico
- **Diferencial**: 3 funcionalidades concretas de IA, não buzzwords
- **Pricing**: 3 tiers clássicos com valores reais, Enterprise sem preço fixo
- **Cores**: roxo (tecnologia/inovação) + verde (crescimento/sucesso) — contraste forte
